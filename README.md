# Свой виджет активности сообщества

> **Проверено на практике:** в настройках сообщества права `app_widget` нет
> (там только управление сообществом, сообщениями, фото, документами,
> историями, стеной и товарами), в OAuth-ключе сообщества — тоже. Сервисный
> ключ приложения VK отклоняет: `method is unavailable with service token`.
> Значит, ключ сообщества с правом `app_widget` можно получить **только**
> через `VKWebAppGetCommunityToken` в Mini App — шаги 1–4 ниже.

Это статическая страница для VK Mini App. Она нужна только для двух действий:

1. добавить Mini App в сообщество;
2. установить виджет и один раз получить ключ сообщества с правом `app_widget`.

Сервера нет. Страница ничего не отправляет наружу и не хранит ключ:
он показывается в поле и копируется в desktop-приложение вручную.

> Это **собственный** виджет. Сторонний виджет «Колизей mini» эта кнопка
> не обновляет: у него свой backend и своё приложение.

## 1. Опубликовать страницу

Нужен любой бесплатный HTTPS-хостинг. Подойдут GitHub Pages или
Cloudflare Pages. Папка `vk_widget` — готовая площадка, файлов два:
`index.html` и `vk-bridge.min.js` (локальная копия VK Bridge, MIT, 4,4 КБ —
чтобы страница не зависела от стороннего CDN).

### GitHub Pages

1. Создайте публичный репозиторий, например `vk-widget`.
2. Загрузите в него содержимое папки `vk_widget`: `index.html` и
   `vk-bridge.min.js` (Add file → Upload files → перетащить оба файла).
3. Включите Pages: **Settings → Pages → Deploy from a branch → main / root**.
4. Через минуту страница будет доступна по адресу вида
   `https://<логин>.github.io/vk-widget/`.

Для этой задачи страница уже опубликована и проверена:
**https://liniad.github.io/vk-widget/** (репозиторий `Liniad/vk-widget`,
ветка `main`, папка `/ (root)`).

Если `vk-bridge.min.js` забыть, страница возьмёт ту же версию 3.0.2 с
`unpkg.com` — работать будет, но появится внешняя зависимость.

### Cloudflare Pages

1. **Workers & Pages → Create → Pages → Upload assets**.
2. Загрузите папку `vk_widget`.
3. Получите адрес вида `https://<имя>.pages.dev/`.

Проверьте, что страница открывается по HTTPS. Секретов в ней нет, поэтому
публичный репозиторий допустим.

## 2. Создать VK Mini App

1. Откройте [dev.vk.com](https://dev.vk.com/) → **Мои приложения** →
   **Создать приложение**.
2. Тип — **Mini App**. Название любое, например «Виджет активности».
3. В настройках приложения укажите **адрес Mini App** — HTTPS-ссылку из
   шага 1.
4. Включите **«Запуск приложения из сообщества»** (без этого не работает
   `VKWebAppAddToCommunity`).
5. Запишите **app_id** — он понадобится на странице и в desktop-приложении.

Платформа: VK Mini Apps (VKontakte), мобильная и веб-версия.

## 3. Открыть приложение внутри VK

Откройте Mini App по адресу `https://vk.com/app<app_id>` (или из сообщества).
Важно: страница должна быть открыта **внутри VK**, иначе VK Bridge недоступен
и кнопки покажут ошибку.

На странице:

1. Проверьте `app_id` и укажите ID сообщества.
2. **«Добавить в сообщество»** — выберите сообщество. Нужны права
   администратора.
3. **«Установить виджет»** — откроется предпросмотр таблицы. Подтвердите
   установку. Это установит виджет с заглушкой; настоящие данные пришлёт
   desktop-приложение.
4. **«Получить ключ»** — VK покажет окно с правом `app_widget`. Ключ
   появится в поле. Скопируйте его.
5. **«Получить токен»** — пользовательский токен с правами `wall, photos,
   groups`. Скопируйте его тоже: он нужен приложению, чтобы читать лайки и
   комментарии участников (статистика виджета). Если кнопка не сработала, есть
   «Запасной способ»: откроется окно VK, а токен вернётся прямо в адрес
   страницы и поле заполнится само.

**Важно про публикацию.** Токен из Mini App VK не разрешает использовать для
загрузки фото на стену: `photos.getWallUploadServer` отвечает
`[15] Access denied: … denied for non-standalone applications`. Такой токен
годится для статистики (чтение стены, лайков, комментариев), но **постить арты
с ним не получится**. Для публикации нужен пользовательский токен
**standalone-приложения** (создаётся на dev.vk.com) с правами `wall, photos,
offline` — его выдают по кнопке «Получить ключ доступа» в настройках такого
приложения. Проверка в «Настройках» приложения теперь сразу говорит, умеет ли
сохранённый токен грузить фото на стену.

Ключи — секреты. Не публикуйте их, не отправляйте в чат и не добавляйте в
репозиторий.

### Если VK пишет «access_token has expired»

Это истёк **пользовательский** токен (личной страницы), а не ключ сообщества.
VK выдаёт такие на срок, и он заканчивается. Починка:

1. обновите токен тем способом, которым он был получен: либо шаги 4–5 этой
   страницы (если токен от Mini App — только для статистики), либо
   «Получить ключ доступа» в настройках standalone-приложения на dev.vk.com
   (если этим токеном публикуете арты);
2. вставьте токен в desktop-приложении: **«Настройки» → «Пользовательский
   токен (wall, photos, offline)»** → «Сохранить»;
3. на вкладке «Виджет» нажмите «Обновить виджет».

Ключ сообщества `app_widget` для чтения стены не подходит: VK отвечает
`method is unavailable with group auth` — проверено на обоих групповых
ключах.

## 4. Вставить ключ в desktop-приложение

1. Запустите `run_desktop.bat`.
2. Откройте вкладку **«Виджет»** (или кнопку «Виджет» в шапке).
3. Заполните:
   - **ID приложения** — `app_id` из VK;
   - **ID сообщества** — можно оставить `0`, тогда возьмётся основное;
   - **Ключ сообщества с правом app_widget** — вставьте ключ;
   - период, количество мест, веса и заголовок.
4. Нажмите **«Сохранить настройки»**.
5. Нажмите **«Обновить виджет»**.

Приложение соберёт статистику, покажет предпросмотр рейтинга и отправит
таблицу в VK. Обновлять можно вручную, когда нужно.

## Автообновление при запуске

В блоке «ОБНОВЛЕНИЕ» есть галочка **«Обновлять виджет при запуске
приложения»** (по умолчанию включена). Тогда сразу после открытия приложение
само собирает статистику и обновляет виджет — ничего нажимать не нужно.

- Сбор идёт в фоне, интерфейсом можно пользоваться.
- Если интерфейс занят (например, грузится каталог), попытка повторяется
  каждые 2 секунды (до 10 раз), а потом пропускается.
- **Лимит VK соблюдается и между запусками**: время последнего обновления
  хранится в конфиге (`widget.last_update_at`), поэтому если открыть
  приложение дважды подряд, второе обновление пропустится со статусом
  «Автообновление пропущено: виджет обновлялся меньше 30 секунд назад».
- Ошибки при автообновлении не показывают модальных окон: текст попадает в
  статус и в лог. Кнопка «Обновить виджет» по-прежнему показывает окно.
- Если виджет ещё не настроен (нет ключа `app_widget`), автообновление просто
  пропускается.

Расписания по времени нет: автообновление срабатывает только при запуске
приложения и только если галочка включена.

Для автотестов и скриптов проверки есть отключатель: переменная окружения
`BOTCHEREZVK_NO_WIDGET_AUTOSTART=1` перед запуском приложения — тогда
автообновление не срабатывает вообще (обычный запуск пользователя не
затрагивается).

## Как считается рейтинг

Для каждого поста сообщества за период (по умолчанию 7 дней):

- `likes.getList` — кто поставил лайк;
- `wall.getComments` — кто написал комментарий (включая ответы);
- `wall.getReposts` — кто сделал репост (если VK отдаёт метод).

Баллы по умолчанию:

```text
баллы = лайки × 1 + комментарии × 2 + репосты × 3
```

Если VK отвечает `Unknown method` на `wall.getReposts`, приложение показывает
одно предупреждение и считает баллы без репостов: `лайки × 1 + комментарии × 2`.

Веса, период и количество мест меняются во вкладке «Виджет».
Сортировка: баллы, затем лайки, комментарии, репосты, имя.

Ограничения таблицы VK:

- до 6 колонок;
- до 11 строк включая заголовок, то есть до 10 участников;
- в первой ячейке можно показывать аватар пользователя (`icon_id = id<user_id>`);
- ссылки — только на `vk.com` и `vk.me`.

Поэтому в виджете: участник, место, лайки, баллы.
Комментарии и репосты в таблицу не выводятся, но в баллах участвуют.

Внизу таблицы — ваша собственная строка со звёздочкой «★». VK не умеет
персонализировать таблицу под зрителя, поэтому эту строку видят все: если вы
не попали в топ, она добавляется последней (топ-9 + вы), если попали — просто
помечается звёздочкой. Ваш профиль определяется по владельцу
пользовательского токена.

Если за период вы ничего не лайкали и не комментировали, вы в рейтинг не
попадаете, и место считается как «последнее + 1»: например, при 73 участниках
будет 74-е, лайки и баллы — 0. Когда участников нет вовсе, в колонке места
остаётся прочерк.

Числовые колонки («Место», «Лайки», «Баллы») выровнены по центру; «Участник» —
по левому краю.

Полный рейтинг виден в предпросмотре desktop-приложения (в окне — до 500
строк, чтобы не зависало на больших сообществах).

## Заголовок и дата обновления

Заголовок берётся из поля «Заголовок виджета» на вкладке «Виджет». К нему
автоматически дописывается дата и время сбора статистики (по Москве),
например:

```text
Активность сообщества · 26.10.2026 10:41
```

- Галочка **«Показывать дату и время в заголовке»** (включена по умолчанию)
  отключает эту приставку.
- Дата — это момент начала сбора статистики (сбор идёт 20–40 секунд, так что
  в заголовке будет время запуска сбора, а не окончания).
- VK ограничивает заголовок 100 символами, поэтому при длинном тексте
  подрезается сначала ваша часть, а дата остаётся целиком.
- В предпросмотре приложения строка «Заголовок: «…»» показывает ровно то,
  что уедет в VK.

## Ограничения

- VK разрешает `appWidgets.update` не чаще **одного раза в 30 секунд**.
- Автоматического обновления по расписанию нет: либо кнопка, либо галочка
  «Обновлять виджет при запуске приложения». При желании приложение можно
  запускать Планировщиком задач Windows, но компьютер должен быть включён.
- Для чтения лайков и комментариев нужен пользовательский токен с доступом
  к стене сообщества. Он уже используется приложением для публикации; при
  ошибке доступа проверьте его права в «Настройках». Если VK пишет
  `access_token has expired`, обновите пользовательский токен — без него
  статистика не соберётся (ключ `app_widget` сам по себе стену не читает).
- Если сообщество закрытое или пост удалён, часть данных может не прочитаться.
  Такие ошибки попадают в предупреждения, обновление не отменяется.

## Частые ошибки VK API

| Код | Что значит | Что делать |
| --- | --- | --- |
| — | `method is unavailable with service token` | Вставлен сервисный ключ приложения. Нужен ключ **сообщества** с правом `app_widget` (см. начало инструкции) |
| 5 | Токен недействителен | Получить ключ заново |
| 15 / 27 | Нет доступа | Нужен ключ администратора сообщества |
| 100 | Неверные параметры | Проверить ID сообщества и настройки |
| 125 | Неверный ID сообщества | Проверить `group_id` |
| 12 | Не удалось скомпилировать код | Сообщить разработчику, проверить таблицу |
| 19 | Контент заблокирован | Проверить текст ячеек |
| 210 / 212 | Нет доступа к стене/комментариям | Проверить права пользовательского токена |

## Файлы

- `index.html` — страница Mini App.
- `vk-bridge.min.js` — локальная копия VK Bridge 3.0.2 (MIT), чтобы не
  зависеть от CDN. Без него страница берёт ту же версию с unpkg.com.
- `README.md` — эта инструкция.

Desktop-приложение: `D:\python\Бот ВК\botcherezvk_desktop.py`,
настройки: `D:\python\Бот ВК\botcherezvk_config.json` (ключ хранится там,
доступ ограничен текущей учётной записью Windows).
