# vk-widget

Статическая страница Mini App для получения ключа сообщества с правом `app_widget` и установки собственного виджета активности.

- `index.html` — интерфейс Mini App (VK Bridge).
- `vk-bridge.min.js` — локальная копия VK Bridge 3.0.2 (MIT).

Секретов в репозитории нет: токены сюда не коммитятся.
