Виджет активности

Мини-приложение для установки собственного виджета сообщества и получения ключа с правом app_widget. Ключ никуда не отправляется: он показывается только вам, чтобы вставить его в desktop-приложение.

Подключение

ID хранятся только в этом браузере.

Шаги

1

Добавить приложение в сообщество не выполнено

Нужны права администратора сообщества. В настройках Mini App должен быть включён «Запуск приложения из сообщества».

2

Установить виджет не выполнено

Откроется предпросмотр таблицы. Установите виджет — дальше desktop-приложение будет обновлять его настоящими данными.

3

Получить ключ сообщества не выполнено

Право app_widget. Ключ может получить только администратор. Вставьте его в desktop-приложении: вкладка «Виджет» → «Ключ сообщества».

Это секрет. Не публикуйте его, не отправляйте в чат и не сохраняйте в репозитории. Desktop-приложение хранит ключ только в локальном конфиге.

Журнал

Готово к работе. Откройте это приложение внутри VK.
